## 한눈에 보기 {#summary}

무엇을 관찰했고 독자가 어떤 판단에 활용할 수 있는지 설명합니다.

## 관찰 환경 {#observed-environment}

| 항목 | 값 |
|---|---|
| 관찰 날짜 | YYYY-MM-DD |
| AWS 리전 | `<AWS_REGION>` |
| 서비스·도구 버전 | 버전 |
| 입력 조건 | 데이터 크기와 주요 설정 |
| 반복 횟수 | 실제 반복 횟수 |

## 관찰한 사실 {#observations}

로그, 측정값과 서비스 응답에서 직접 확인한 사실만 기록합니다.

## 해석 {#interpretation}

관찰에서 도출한 해석을 사실과 분리해 설명합니다.

## 재현 방법 {#reproduction}

다른 독자가 같은 조건에서 확인할 수 있는 완전한 절차를 작성합니다.

## 일반화할 수 없는 조건 {#limitations}

한 번의 실행, 특정 리전, 특정 버전 또는 입력 데이터에만 해당하는 조건을 설명합니다.

## 후속 검증 항목 {#follow-up-validation}

결론을 확대 적용하기 전에 추가로 검증해야 할 항목을 기록합니다.
