## 고객에게 공유하기 전에 확인할 것

1. 문서가 고객에게 공개 가능한 자료인지 확인합니다.
2. 마지막 검토일과 문서의 측정 환경을 확인합니다.
3. AWS 서비스의 현재 제공 리전과 요금을 공식 문서에서 다시 확인합니다.
4. 규제 관련 내용은 고객의 법무·보안·품질 담당자와 적용 범위를 확인합니다.
5. 명령과 실습은 고객 계정에 적용하기 전에 별도 테스트 환경에서 검증합니다.

## 콘텐츠 유형

- **입문:** 처음 개념과 선택지를 이해하는 자료
- **실습:** 사용자가 단계별로 따라 하는 자료
- **아키텍처:** 여러 서비스를 조합하는 설계 자료
- **성능·비용 분석:** 특정 환경에서 측정한 결과
- **문제 해결:** 증상, 원인과 해결 절차
