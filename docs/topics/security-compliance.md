# 보안·규제 준수

AWS 계정과 데이터를 보호하고 규제 대상 시스템의 통제를 설계할 때 참고할 수 있는 자료입니다.

## 계정과 접근 보호

- [AWS 계정 안전하게 지키기](/aws/account-security/)
- [루트 계정 보호하기](/aws/otp/)

## 규제 대상 시스템

- [한국 제약·바이오를 위한 GxP on AWS](/gxp-on-aws/)
- [AWS 공동 책임 모델](https://aws.amazon.com/compliance/shared-responsibility-model/)
- [AWS 규제 준수 프로그램](https://aws.amazon.com/compliance/programs/)

GxP는 의약품과 의료기기의 품질, 안전성과 데이터 신뢰성을 유지하기 위한 규정과 품질관리 원칙을 통칭합니다.

## 감사·규제 자료

- [AWS Artifact](https://aws.amazon.com/artifact/)
- [AWS Config](https://aws.amazon.com/config/)
- [AWS CloudTrail](https://aws.amazon.com/cloudtrail/)

감사 자료는 시스템이 규정과 조직의 통제 기준에 맞게 운영됐음을 확인하는 증거입니다.

:::caution
AWS 서비스의 기술 기능만으로 규제 준수가 완성되지는 않습니다. 적용 규정, 시스템의 의도된 용도와 고객의 품질·보안 절차를 함께 검토해야 합니다.
:::
