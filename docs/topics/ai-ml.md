## AI 에이전트와 지식 활용

- [AI Agent Memory on AWS](/ai-agent-memory-on-aws/)

멀티모달 분석은 텍스트, 이미지, 유전체처럼 서로 다른 형태의 데이터를 함께 분석하는 방법입니다.

## 적용 전 확인사항

- 입력 데이터에 개인정보나 민감정보가 포함되는지 확인합니다.
- 모델과 기능의 제공 리전을 확인합니다.
- 결과를 사람이 검토해야 하는 업무인지 정의합니다.
- 품질, 비용과 응답 시간을 실제 데이터로 측정합니다.
- 최신 서비스 사양은 [AWS 공식 문서](https://docs.aws.amazon.com/)에서 확인합니다.
