# Start with what you want to accomplish

You do not need to know the AWS service name first. Choose the goal that most closely matches your problem. This page links only to content currently available in English.

## I want to start an AWS account safely {#i-want-to-start-an-aws-account-safely}

Begin with the official [AWS Security, Identity, and Compliance documentation](https://docs.aws.amazon.com/whitepapers/latest/aws-overview/security-services.html). The detailed account-basics series in this collection is currently available only in Korean.

## I want to build a research computing environment {#i-want-to-build-a-research-computing-environment}

Review the official documentation for [Research and Engineering Studio on AWS](https://docs.aws.amazon.com/res/latest/ug/what-is-res.html) and [Amazon Lightsail for Research](https://docs.aws.amazon.com/lightsail-for-research/latest/ug/what-is-amazon-lightsail-for-research.html). Additional field guides will be added after English review.

## I want to store and deliver data {#i-want-to-store-and-deliver-data}

Start with the [Amazon S3 User Guide](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html). For genomics workflows, also review how workflow duration affects [AWS HealthOmics run storage cost](../omics-on-aws/aws-healthomics-ksh.md).

## I want to run large-scale analyses {#i-want-to-run-large-scale-analyses}

- [Run nf-core/sarek on AWS HealthOmics](../omics-on-aws/aws-healthomics/aws-healthomics-nf-coresarek-390.md)
- [Connect AWS HealthOmics workflows to a VPC](../omics-on-aws/aws-healthomics/vpc-connected-workflows-s3.md)

A workflow is a defined sequence of analysis steps that runs automatically with specified inputs, conditions, and outputs.

## I want to apply AI and machine learning {#i-want-to-apply-ai-and-machine-learning}

- [Design antibody candidates with Amazon Bio Discovery](../amazon-bio-discovery-ai/amazon-bio-discovery-ai.md)

The guide explains the key concepts for life science researchers before walking through the console workflow.

## I want to review security or regulatory requirements {#i-want-to-review-security-or-regulatory-requirements}

Use the official [AWS Compliance documentation](https://aws.amazon.com/compliance/) as the primary source. Technical controls alone do not establish regulatory compliance; confirm the applicable requirements with the customer's legal, security, and quality teams.
